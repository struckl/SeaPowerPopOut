# Workshop feature lists (pick one for description.bbcode)

`description.bbcode` uses list B. To use list A instead, replace the two `[list]` blocks under "What you get" with it.

## A. Core features only

```bbcode
[list]
[*][b]Pop-out button[/b] on every window: one click moves it to your second monitor, one click brings it back.
[*][b]Windows stay where you put them[/b]: position and size come back in the next mission, on both screens.
[*][b]Better window handling[/b]: double-click a title bar to maximize, windows snap to edges and to each other, wide resize corners.
[*][b]Window look[/b]: make any window see-through, scale it, or keep it above or below the others.
[*][b]A much better Encyclopedia[/b]: search in ids and descriptions, readable loadout names, "Armed only", a resizable unit list.
[*][b]Unit Status gets a Reference tab[/b] with the unit's data and loadouts, right where you need it.
[/list]
```

## B. Full list (the one I would use)

```bbcode
[h2]Second monitor[/h2]
[list]
[*][b]Pop-out button[/b] on the formation manager, message log, unit status, camera, sensor and doctrine windows. One click moves the window to your second monitor, the same button brings it back.
[*]Over there only the windows show, your desktop stays visible around them. They snap to each other and to the monitor edges and can be bigger than the game normally allows.
[*]Popped-out windows come back on the second monitor in the next mission, where you left them.
[/list]

[h2]Every window, on every screen[/h2]
[list]
[*]Position and size are remembered, also after a restart.
[*]Double-click the title bar to maximize, double-click again to restore.
[*]Windows snap to the screen edges and to each other. Wide resize corners and proper resize cursors.
[*]Look button: opacity, scale, text outline, and whether a window stays below or above the others.
[*]Gear button with all settings, in the game's nine languages.
[*]Optional desktops: Tab switches between window layouts (off by default, see the settings).
[/list]

[h2]Encyclopedia[/h2]
[list]
[*]Search finds unit ids and words from the description too. "Type 072" finds the Yukan class.
[*]Loadout variants get real names ("Long-Hull [Early]") instead of bare years, sorted by service date.
[*]A click on a class opens its earliest variant.
[*]"Armed only", and the country list only offers countries that have units for your search.
[*]Drag the edge of the unit list to make it wider, or hide it. The wheel scrolls the list only when the mouse is over it.
[*]Weapon and sensor links show their description as a tooltip.
[*]Your country, category and search stay set for the next time.
[/list]

[h2]In a mission[/h2]
[list]
[*]Unit Status: full unit name, a Reference tab with the unit's data and loadouts, taller damage control sections.
[*]Right-click the flag or name in the unit panel for the unit's menu (also for contacts).
[*]The time panel can be dragged anywhere. The corner messages no longer block clicks on the map.
[/list]

[h2]Campaign[/h2]
[list]
[*]Task Force Builder: loadouts listed oldest first, a "Strict loadouts" option on the start screen.
[*]Damaged ships can be dismissed, and the hull-swap price is fixed.
[/list]
```
