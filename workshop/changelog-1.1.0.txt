Big update: Pop-Out Windows now handles the game's windows on every screen, not only the second monitor. Windows remember their place and size, snap, maximize on double-click, and can be made see-through. The Encyclopedia gets a real search (ids and descriptions), readable loadout names, Armed only and a resizable unit list. Unit Status gets a Reference tab, the time panel can be moved, and the campaign Task Force Builder lists loadouts by date. Every part can be switched off with the new gear button.
